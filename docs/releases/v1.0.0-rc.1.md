# Blossom v1.0.0-rc.1

Release candidate. This is not stable `v1.0.0`.

The image workflow publishes `1.0.0-rc.1` and an immutable `sha-` tag. It does not move `latest`,
`1`, or `1.0` for this prerelease. The live Blossom service is not deployed by the tag.

`v1.0.0-beta.1` stays where it is. There is no GitHub Release named `v1.0.0`.

Self-hosting SmartFlowSocial does not require this service. The internal publisher and reader ship
in the main application.
